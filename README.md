# Apps Distribution 📦

Repositori publik untuk distribusi file APK dan `config/catalog.json` aplikasi **Apps Store**.

File-file di repositori ini disinkronkan secara otomatis dari repositori pengembangan private melalui GitHub Actions.

## Struktur:
- `config/catalog.json`: Daftar katalog aplikasi, versi, dan informasi unduhan.
- `apks/`: Berkas APK aplikasi Android siap pasang.
