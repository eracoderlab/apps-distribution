# Apps Distribution 📦

Repositori publik untuk penyimpanan dan distribusi berkas APK aplikasi Android dari **Hub Store**.

Berkas di repositori ini disinkronkan secara otomatis dari repositori pengembangan private melalui GitHub Actions.

> [!NOTE]
> Metadata dan katalog aplikasi kini dikelola langsung secara realtime melalui database, sehingga berkas `config/catalog.json` sudah tidak digunakan lagi.

## Struktur Repositori:
- `apks/` : Berkas APK aplikasi Android siap pasang (misal `apks/noteme/noteme-v1.0.0.apk`).
- `assets/` : Aset ikon dan tangkapan layar pendukung aplikasi.
